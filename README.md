# Simple AI Inference Analyzer

Aplikasi Python mudah untuk membaca, menapis, menganalisis
dan memvisualisasikan data simulasi inferens AI.

## Objektif

- Membaca data CSV menggunakan pandas.
- Menapis data berdasarkan nilai confidence.
- Mengira statistik menggunakan NumPy.
- Menghasilkan carta menggunakan Matplotlib.
- Mengurus kod menggunakan Git dan GitHub.

## Keperluan

- Python 3
- pandas
- NumPy
- Matplotlib

## Pemasangan

pip install -r requirements.txt

## Menjalankan aplikasi

python main.py

## Output

Aplikasi menghasilkan:

- output/filtered_data.csv
- output/object_count.png

## Nota

Projek ini menggunakan komputer sebagai simulasi sebelum
pelaksanaan sebenar pada NVIDIA Jetson.
